Floorplan Change Detection

How a new airport floorplan (PDF or image) is turned into a structured map of what is where, quality-checked, compared with the previous version, and reported as a list of real changes. Colour, icon and layout restyles are deliberately ignored.

AI agent (vision model) Deterministic step Decision Storage Quality loop

What counts as a change

Reported

  • Replaced — Starbucks → Costa Coffee in the same spot
  • Repurposed — a shop becomes a toilet
  • Added / removed — a new lift, a missing ATM
  • Moved — the same prayer room in a new location
  • Renamed — small name changes on the same place
  • Relation changed — Emirates moves from desk 14 to desk 5

Ignored (presentation only)

  • New colour scheme or icon style
  • Map rescaled, shifted or exported in a different format
  • Legend reordered or marker codes renumbered
  • Café ↔ restaurant reclassification of the same place
  • Re-uploading a byte-identical file (skipped entirely)

Agents at a glance

#AgentJobRule
1UnderstandingReads the legend and scans the map tile by tile to list every label: toilets, desks, cafés, lifts, gates…Fixed category list, positions on a 0–1 page grid
2Mapping confidenceA sceptical reviewer scores each entry against image crops; PDF text is used as hard evidenceAverage must be ≥ 0.9
3CorrectionFixes the entries the reviewer doubted; only changed entries are re-scoredMax 1 round, then continue
4Change detectionAligns the old and new maps and pairs up entries to find what really changedMeaning only, never styling
5Change confidenceLooks at old vs new crops for each change to confirm it is realVisual check 60 % + mapping evidence 40 %
6ReportingWrites the change report and stores the new versionRejected changes listed separately

Under the hood

Model-agnostic

Agents talk to a neutral vision-model interface. Claude is used today; Gemini or GPT can be plugged in without changing the agents.

Tested on synthetic edits

8 edited copies of real MapsPeople maps (renamed cafés, moved desks, removed toilets, plus recoloured & rescaled copies) measure recall and false alarms.
