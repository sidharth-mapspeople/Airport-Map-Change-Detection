**Edit** cases measure recall (did it find what changed?). **Restyle** cases measure false alarms:
the content is identical, so any reported change is a false positive.

## Running

```bash
PYTHONNOUSERSITE=1 python scripts/make_test_edits.py      # regenerate (deterministic)
PYTHONNOUSERSITE=1 python scripts/evaluate_edits.py -v    # needs an API key; writes eval_results/<timestamp>/
PYTHONNOUSERSITE=1 python scripts/evaluate_edits.py --cases bru-departure-edits bru-departure-restyle
```

The evaluator stores each original as v1 of an `eval-…` map in `eval_data/` (reused across runs), processes each
variant, diffs it against v1 with change-confidence scoring, and matches reported changes to the manifest
(type, names, category and location within 0.04 page units). It reports found / missed / false positives /
wrongly rejected changes and the mapping confidence of both versions.
